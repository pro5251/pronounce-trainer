# 從圖片收集單字（設計）

## 目的
使用者在手機上截到或拍到含英文的畫面（多半是 Grafana／告警畫面）時，不想逐字手打。上傳圖片後，網站找出詞庫和備忘錄裡都還沒有的英文字，讓使用者勾選要加入的字。勾選的字進「新增／備忘錄」，之後沿用現有流程：查翻譯和音標 → 送到每日更新 → 19:00 加進詞庫。

## 目標／非目標
- 目標：手機上可用（選圖或用相簿的截圖），由使用者勾選，跟現有備忘錄無縫銜接。
- 非目標：辨識片語或句子（照舊手打）、伺服器端處理、自動加進詞庫。
- 不可以：未經使用者勾選就加入任何字；把圖片上傳到任何地方。

## 限制
純靜態網站，沒有後端、沒有建置步驟。外部程式庫只能用 CDN 載入。

## 做法比較
- **A. 瀏覽器內 OCR（Tesseract.js）**（採用）：免費、圖片不離開手機。第一次使用要下載約 4–5 MB，乾淨的截圖很準。
- B. 使用者自備 Claude API 金鑰：比較準，也能抓片語，但金鑰要存在瀏覽器裡，而且每張圖要付費。
- C. 圖片附在 GitHub issue，交給排程辨識：要等到隔天，沒辦法當場勾選。
- 使用者表示交給 Claude 決定，所以採用 A。

## 設計
- 在備忘錄卡片加一個「📷 從圖片找單字」按鈕（`<input type="file" accept="image/*">`）。在手機上可以選相簿，也可以直接拍照。
- 點下按鈕後才用動態 `import()` 從 jsDelivr 載入 `tesseract.js@5.1.1`，語言用 `eng`，平常開頁面不會載入。辨識時顯示進度（載入中 / 辨識中 xx%）。
- 抽字邏輯（`core.js` 的純函式 `extractWords(text)`，附單元測試）：
  - 以英文字母序列切字，允許字中間有 `'` 或 `-`（例如 `don't`、`read-only`），去掉頭尾的標點。
  - 去掉：長度 < 2 的字、含數字的字、看起來像網址／路徑／主機名稱的字（含 `.`、`/`、`_`、`=`、`:`），並以小寫去重。全大寫的字（例如 `CPU`）保留原樣，其餘轉成小寫。
  - 先去掉頭尾標點再檢查，所以 `exceeded.`、`Summary:`、`[FIRING:1]` 裡的字會保留。
  - CamelCase 的告警名稱拆成單字（`HighLatency` → `high`、`latency`）。（實作時 Claude 的決定）
  - 依圖片中出現的順序排列。
- 用 `inLibrary()` 和現有備忘錄比對，把已經有的字隱藏，只顯示「已隱藏 n 個」。
- 候選字顯示成可勾選的小方塊，預設全不勾。另有「全選／全不選」和「加入備忘錄（n）」。加入的字附備註「來自圖片」，並跑現有的 `lookupMemo()`。
- 錯誤處理：載入失敗（例如離線）或辨識不到字時，顯示說明文字。

## 交給實作者
樣式細節、進度文字、第一次下載的提示文字。
